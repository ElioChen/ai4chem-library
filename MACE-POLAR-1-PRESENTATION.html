⚙️ Methodology

6 min 核心：非自洽场（non-SCF）电荷密度 + Fukui 归一化

✅ 已核对原文（arXiv:2602.19411, ar5iv 全文）——以下为论文真实方法，非推测。

E_local：短程/共价项（MACE 骨架） ├─ 等变神经网络，多体相互作用 └─ 处理化学键、Pauli 排斥等短程效应 自旋-电荷密度层 ├─ 原子中心高斯基展开的"粗粒化"电子密度 ├─ 分 spin-up / spin-down 两通道（支持变电荷、变自旋态体系） └─ 通过 Coulomb 卷积计算静电势，再投影回原子特征 迭代极化更新（非自洽，避免真正 SCF 高成本） ├─ 用势场反复修正原子多极矩，模拟"极化响应" └─ 用可学习的 Fukui 函数（概念密度泛函思想）强制总电荷/自旋守恒 E_electrostatic：长程库仑项（来自"抹平"的多极矩） E_non-local：学习到的修正项（色散等） 总能量 = E_local + E_electrostatic + E_non-local

为什么比标准 MLIP 更强？

  • 训练规模：OMol25 数据集 1 亿个 hybrid DFT 构型，64×H200 GPU 训练
  • 关键设计：用非自洽迭代 + Fukui 归一化，绕开真正 SCF 极化的高计算成本
  • 通用性：同一模型覆盖小分子、分子晶体、蛋白-配体复合物等多尺度体系
  • 最大亮点：对需要长程静电的体系（大型结合口袋）提升幅度远超短程模型

与标准（短程）MACE 的关键区别

要素 标准 MACE（短程） MACE-POLAR-1
静电处理 无显式长程项 电荷密度 + Coulomb 长程项
极化响应 无 非自洽迭代更新多极矩
电荷/自旋守恒 — Fukui 函数强制归一化
大体系（如完整活性位点） 误差可达 ~30 kcal/mol 误差 ~3-4 kcal/mol（数量级提升）

6 min Core: Non-SCF Charge Density + Fukui Normalization

✅ Verified against the paper (arXiv:2602.19411, full text via ar5iv) — not speculation.

E_local: Short-range/covalent term (MACE backbone) ├─ Equivariant NN, many-body interactions └─ Handles bonding, Pauli repulsion (short-range) Spin-Charge Density Layer ├─ Coarse-grained electron density, atom-centered Gaussian basis ├─ Split into spin-up/spin-down channels (variable charge/spin states) └─ Coulomb convolution → electrostatic potential → projected back to atomic features Iterative Polarization Updates (non-self-consistent, avoids true SCF cost) ├─ Repeated refinement of atomic multipoles mimics polarization response └─ Learnable Fukui functions (conceptual DFT) enforce charge/spin normalization E_electrostatic: long-range Coulomb from smeared multipoles E_non-local: learned corrections (e.g. dispersion) Total Energy = E_local + E_electrostatic + E_non-local

Why Stronger Than Standard MLIP?

  • Scale: Trained on 100M hybrid-DFT structures from OMol25, 64×H200 GPUs
  • Key design: Non-SCF iteration + Fukui normalization avoids the cost of true self-consistent polarization
  • Universality: One model spans small molecules, molecular crystals, protein-ligand complexes
  • Headline result: Largest gains on systems needing long-range electrostatics (large binding pockets)

vs. Standard (Short-Range) MACE

Aspect Standard MACE (short-range) MACE-POLAR-1
Electrostatics No explicit long-range term Charge density + long-range Coulomb
Polarization response None Non-SCF iterative multipole updates
Charge/spin conservation — Enforced via Fukui functions
Large systems (full active sites) Error up to ~30 kcal/mol ~3-4 kcal/mol (order-of-magnitude gain)
