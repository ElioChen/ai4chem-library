# AI4Chem 文献库 📚

一个由 AI 驱动的分子机器学习文献与工具自动收集系统。每周五 06:00 (荷兰时间) 自动检索最新研究进展、整理归档、发现有趣的开源项目（原为每日执行，2026-09-07 起改为每周一次以降低 token 消耗）。

## 🎯 覆盖范围

**学术平台**：arXiv (cs.LG, physics.chem-ph, cond-mat.mtrl-sci, q-bio.BM)、ChemRxiv、bioRxiv

**研究方向**（分子机器学习全景）：
- 🏗️ 基础模型与势函数：Foundation MLIP、神经网络势函数、DFT 替代
- ⚛️ 分子表示学习：图神经网络、等变神经网络、分子编码
- 🔗 反应与过渡态：反应预测、过渡态搜索、反应路径规划
- 🎨 生成与优化：分子生成、扩散模型、生成模型化学
- 🧪 催化与应用：催化剂发现、高通量筛选、药物设计、材料设计

## 📖 使用指南

- **去重索引**：`index.json` — 所有已收录论文的 arXiv ID、DOI、时间戳
- **按月归档**：`YYYY-MM.md` — 每月新增论文详情（标题、作者、摘要、标签）
- **自动化配置**：`ROUTINE_PROMPT.md` — 云端 Routine 的执行流程定义

## 🔧 相关开源项目

### 2026-10-08 本次发现

- **[NVIDIA/nvalchemi-toolkit](https://github.com/NVIDIA/nvalchemi-toolkit)** — ⭐ 189，最近提交 2026-10-07，Python，Apache-2.0（公开 Beta）
  ① NVIDIA 推出的"GPU-first"原子级模拟 Python 框架，支持批量化分子动力学、几何优化，以及机器学习势函数的训练/微调与多 GPU 扩展。
  ② 作为大厂级别的 MLIP 工具链，把"训练-模拟-主动学习"整条流水线标准化，对需要规模化跑 MLIP 的科研/工业团队很有参考价值，且提交非常活跃（过去一周多次更新）。

- **[microsoft/syntheseus](https://github.com/microsoft/syntheseus)** — ⭐ 212，最近提交 2026-10-07，Python，端到端逆合成规划包
  ① 将搜索算法（如 MCTS、Retro*）与多种单步反应预测模型解耦、统一接口封装，方便公平对比不同逆合成方法。
  ② 由 Microsoft Research 维护，更新频率高（近几个月几乎每周都有提交），是目前逆合成算法基准测试的事实标准之一，便于快速搭建自己的路线规划 pipeline。

- **[chemprop/chemprop](https://github.com/chemprop/chemprop)** — ⭐ 2.5k，最近提交 2026-09-01，Python，MIT
  ① 基于消息传递神经网络（MPNN）的分子性质预测库，v2.0 为彻底重写版本，支持多分子输入、反应、原子/键级性质与光谱预测。
  ② 作为分子性质预测领域最成熟、社区最大的开源工具之一，长期保持活跃维护，是入门/生产环境下做 QSAR 和性质预测任务的首选基线工具。

## 🤖 关于自动化

本仓库由 Claude Code 云端 Routine 驱动，每周五 06:00 荷兰时间自动执行以下任务：
1. 用 web_search 检索分子 ML 相关的最新论文预印本
2. 自动编写摘要、标注研究方向标签
3. 维护 JSON 去重索引与月度 Markdown 归档
4. 发现并推荐相关的开源项目
5. Git commit 并提交更新

更多详情见 `ROUTINE_PROMPT.md`。
